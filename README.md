# 蒙版工坊 · Mask Studio

一个纯前端的图片蒙版合成工具。用来解决 **AI 改图改多了会出现条纹、斑点、塑料感** 的问题。

不需要安装、不需要联网、不上传任何图片。双击 `index.html` 就能用。

---

## 它解决什么问题

AI 局部重绘（inpaint / 扩图 / 去物体）有个通病：同一块区域被反复重绘几次之后，
笔触、纹理、噪点会一层层叠加，最后出现条纹、色斑，越改越花。

蒙版工坊本身**不参与生成**，它只负责「缝合」：

- **底层图** = 原图，完整保留，一个像素都不动
- **上层图** = AI 生成的那张
- 用画笔把上层图里想要的部分涂出来，其余区域仍然是原图的原始像素

这样每次改动只发生在真正需要改的地方，不用整张重新生成、也不用反复过一遍 AI。
相当于手工控制一张 PS 蒙版，但不用开 PS。

## 使用方法

1. **下载**：点右上角 `Code → Download ZIP`，解压到任意文件夹（或 `git clone`）。
2. **打开**：双击 `index.html`，或把文件拖进浏览器。
3. **导入**：把原图拖进窗口 —— 第一张作为底层图，再拖入的作为上层图；
   也可以点面板里的「导入底层图 / 导入上层图」。
4. **涂抹**：在画布上按住左键涂，涂到哪里，上层图就在哪里显现。
   涂多了按 `E` 切橡皮擦掉。
5. **调边缘**：默认柔度 60% 过渡比较自然；贴图、阴影这类硬边内容可以拉到 0%。
6. **导出**：点右下角「导出」，尺寸和格式自动跟随底层图。

> 拖放时按住 `Shift`，可以把这张图强制当作底层图。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 涂抹 / 擦除 | 鼠标左键 |
| 平移画布 | 空格 + 拖动，或右键拖动 |
| 缩放画布 | 滚轮 |
| 笔刷大小 | `[` / `]` |
| 画笔 / 橡皮 | `B` / `E` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 适应窗口 / 100% | `0` / `1` |

## 导出规则

导出**没有选项**，严格跟随底层图：

- **尺寸**：底层图多大就导出多大，不缩放、不超分
- **格式**：底层图是什么格式就导出什么（PNG 无损，JPG / WEBP 质量 95）
- 浏览器无法编码的格式（GIF、BMP、AVIF 等）会自动回退成 PNG

如果图片超过 5000 万像素，会自动按比例降采样并在界面上提示。

## 说明

- 图片只在浏览器内存里处理，**不会上传到任何地方**，关闭页面即清空
- 建议使用较新版本的 Chrome / Edge / Firefox / Safari
- 想在线分享的话，仓库 `Settings → Pages` 选 `main` 分支根目录即可（纯静态，无需构建）
- 柔边笔刷是把一整笔当成一条路径、多层描边叠加实现的，不是一颗颗盖章，
  所以边缘不会因为反复涂抹而变硬
